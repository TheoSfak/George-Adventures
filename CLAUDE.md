# George Adventures at Agios Vlasis — project handoff

This file is read automatically by Claude Code. It carries over the conversation from the Claude chat session where this project was started (2026-10-12) and records everything built since.

## Who / what
- Owner: Theodore (Greek/English, Windows 11). Prefers getting things DONE over step-by-step walkthroughs; wants precise, situation-specific answers. Often writes Greeklish.
- Goal: a full 3D RPG named **"George Adventures at Agios Vlasis"** (in-game Greek title: *Οι Περιπέτειες του Γιώργου στον Άγιο Βλάση*), starting with ONE map. Built mainly by AI, so everything must be AI-editable (plain-text scenes/scripts).
- Constraint: **only free tools**. Quality bar: must look good; stop and say so if it can't.
- **ALL IN-GAME TEXT MUST BE GREEK** (UI, quests, lore, dialogue, item names, prompts). Code, comments and file names stay English. Strings live in `scripts/strings_el.gd`, `scripts/quest_data.gd`, `scripts/villager_data.gd`, `scripts/skill_data.gd`. When editing Greek files use the Write/Edit tools (UTF-8); a Python/bash heredoc can mangle text on Windows.

## Decisions already made (and why)
- **Engine: Godot 4.7 (free, MIT)** — NOT Unreal. Godot stores scenes/scripts as text, so AI can edit everything.
- **Art: KayKit (CC0)**: Adventurers (Knight = George, NPCs), Skeletons (enemies), Medieval Hexagon (buildings, nature, props), Dungeon Remastered (chests, coins, potions, kegs, torches, banners), Furniture Bits (interiors), Halloween Bits (crypt/graveyard). Stylized look; realistic AAA is not possible with free assets + AI.
- Other free tools planned: Blender, Poly Haven/ambientCG, Mixamo, freesound.org, Git/GitHub.
- Godot is installed per-user at `%LOCALAPPDATA%\Programs\Godot\Godot.exe` (also on PATH as `godot` via winget). Desktop shortcut "George Adventures (Godot)" opens the project in the editor.

## How to run / test
- **Resolution:** the window opens at 1920x1080 (`window_width_override`/`window_height_override` in `project.godot`); the HUD is still laid out for a 1280x720 base viewport and `canvas_items` stretching scales it 1.5x, while the 3D view renders natively at 1080p (60 fps on the GTX 1050 Ti). **F11** toggles borderless fullscreen. Test drivers take `--resolution`; use `1920x1080` to match the real game.
- Play: open the project in Godot and press F5 (main scene `scenes/main.tscn`).
- After adding a new `class_name` script or assets run `godot --headless --import` once (refreshes the class cache).
- Test drivers in `tools/` use simulated input and take screenshots (windowed, GTX 1050 Ti ok): `godot --path . --resolution 1280x720 --script tools/<name>.gd -- <outdir>`. Always `await process_frame` first and set `root.get_node("/root/Quests").intro_seen = true` (autoloads are not available at compile time in `--script` mode, and the prologue dialogue would block input).
  `controltest` (WoW controls), `playtest` (combat), `loottest` (XP/loot), `skilltest` (skills/bar/potions), `questtest` (whole story), `interiortest` (doors/rooms), `villagertest`, `mobtest` (new mobs), `minimaptest`, `sidequesttest`, `guardtest`, `savetest`, `menutest`, `audiotest`, `daytest`/`eventtest`/`nightinterior`/`shelter`/`skytest` (day/night + invasion), `shoptest` (shop window, equipment, stats), `talenttest` (talent tree + the 6 new skills), `keepertest` (shopkeepers, R flow, respec shrine), `maptest` (map screenshots), `perftest` (fps; 60 fps everywhere). Do not type-reference `Npc` or `Catacombs` in a test (its script mentions `Quests`): use `n.get("npc_id")`.

## What exists (all tested)
**Player** (`player.gd`): WoW-style controls — free cursor, hold RMB = look+steer (A/D strafe), hold LMB = orbit camera, both = run forward, W/S, A/D turn, Q/E strafe, wheel zoom, Shift run, Space jump, quick LMB click (also while RMB is held and he runs: `Player.CLICK_MAX` 0.3 s; both buttons held longer than that run forward) / F / J = 5-hit combo (see "Levels 21 to 40 and faster combat"), K / Ctrl block (attack while blocking = shield bash), V dodge roll, R interact, H health potion, 1-8 action bar, P skill book, T talent tree, I equipment, gamepad. Mouse look only starts from clicks that reach the game (not UI). Health, XP/levels (max 40, +10 hp +2 dmg per level), gold, consumables, death/respawn at the village start.

**Skills & action bar** (`skill_data.gd`, `icons.gd`, `action_slot.gd`, HUD): 8-slot bar (keys 1-8, click, drag & drop, right-click clears), skill book (P). Skills unlock by level: Δυνατό Χτύπημα (1), Ασπίδα του Αγίου (2), Σίφουνας (3), Ευχή του Αγίου (4), Εφόρμηση (5), each with cooldown. Potions: Υγείας / Δύναμης / Ταχύτητας (buff timers shown). Icons are drawn in code. **Ασπίδα του Αγίου** (`guard`, 5 s + talents) makes George untouchable: `Player.take_damage` returns at once through `_guard_absorb()` (a short sound and ring, no damage, no stagger, no knockback). The block key (K / Ctrl) still takes 15% of a frontal hit; `take_damage(amount, from, ranged)` has `ranged = true` for arrows and magic orbs (`Projectile` passes it), and a blocked ranged hit does not push George back (a blocked melee blow moves him 2.5 m/s). Test: `shield_test` (headless).

**World** (`village.gd`, `terrain.gd`, `shaders/*.gdshader`): ~17x bigger map (hex radius 12, ~200 m), buildings at 2.4x scale, procedural meadow ground shader (no hex tiles), cobbled spokes + dirt roads with soft edges, ~40k swaying grass tufts and flowers (MultiMesh chunks), vegetable gardens with fences and scarecrows beside the houses, flower bed around the well, a pond, story areas: west skeleton camp, SE quarry, north crypt/graveyard; mountains + forest ring as the edge; signposts; chests; quest items with golden light beams.

**Shops & equipment** (`shop_data.gd`, `shop_window.gd`, `stats.gd`): **Κυρά-Ελένη** (market) and **Νικήτας** (blacksmith) stand inside their buildings (`"shopkeeper"` in `interiors.gd` DEFS, NPC data in `quest_data.gd` with a `"shop"` key). Market: potions incl. the new Μεγάλο Φίλτρο Υγείας (level 8), buys skeleton junk (Κόκαλο/Σκουριασμένη Λεπίδα/Φυλαχτό, dropped by enemies). **Talent tree** (`talent_data.gd`, `hero_window.gd`, `talent_node.gd`): 3 branches (Φρουρός, Πολεμιστής, Άγιος) x 9 talents, 1 point per level from level 2 (39 at level 40; the stat talents have 2 extra ranks), tiers open at 0/5/10 points in the branch. 6 new active skills come from the tree (Κραυγή Πρόκλησης, Τείχος, Αιματηρή Μανία, Κεραυνός του Πολέμου, Θεία Φλόγα, Ιερός Κύκλος) plus the passive Ανάσταση; talents also upgrade the old skills. ## Technical notes
- Collision layers: 1 world, 2 player (mask 1+16), 4 enemies (mask 1+2), 16 NPCs/villagers. Anything in group `interactables` implements `interact_prompt()`, `interact_range()`, `interact(player)`.
- Imported glb animations don't loop automatically: scripts set loop mode by name.
- KayKit characters face +Z; model yaw = atan2(x, z). Hex pack models are tiny at scale 1 (props use PS=7, buildings BS=12, trees TS=9.5).
- A long skill animation (e.g. spin) must be ended by a timer, not by the animation (`_end_skill_attack`).
- Known gaps / ideas: enemies have no pathfinding (can snag on buildings), camera can clip into an enemy behind George,  invasion has no village guards/allies, Skeleton Rogue/Mage not used yet, `_to_delete/` still present (safe to delete).
