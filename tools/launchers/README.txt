Οι Περιπέτειες του Γιώργου στον Άγιο Βλάση  (George Adventures at Agios Vlasis)

ΕΚΚΙΝΗΣΗ
Τρέξε το GeorgeAdventures.exe. Δεν χρειάζεται εγκατάσταση.

ΑΝ ΤΑ WINDOWS ΤΟ ΜΠΛΟΚΑΡΟΥΝ
Το αρχείο δεν είναι ψηφιακά υπογεγραμμένο, γι' αυτό τα Windows μπορεί να προειδοποιήσουν.
 - SmartScreen ("Windows protected your PC"): πάτα  More info  και μετά  Run anyway.
 - Smart App Control ("blocked an app that may be unsafe"): δεν έχει κουμπί.
   Κάνε δεξί κλικ στο zip -> Ιδιότητες -> Κατάργηση αποκλεισμού (Unblock) -> OK
   και βγάλε ξανά τα αρχεία σε ΝΕΟ φάκελο. Αν μπλοκάρει ακόμα, μπορείς να κλείσεις
   το Smart App Control από τις Ρυθμίσεις ασφαλείας των Windows (δική σου απόφαση).

ΑΝ ΤΑ ΓΡΑΦΙΚΑ ΦΑΙΝΟΝΤΑΙ ΜΑΥΡΑ Ή ΣΠΑΣΜΕΝΑ
Ρυθμίσεις -> Γραφικά -> Μεσαία -> Εφαρμογή και επανεκκίνηση.
Αν δεν φτάνεις στο μενού, δοκίμασε το Play-Mobile-Renderer.bat
(ή το Play-Compatibility-Renderer.bat για πολύ παλιές κάρτες γραφικών).

ΕΝΗΜΕΡΩΣΕΙΣ
Όταν υπάρχει νέα έκδοση, εμφανίζεται μια κάρτα στο αρχικό μενού. Πάτα «Ενημέρωση».
