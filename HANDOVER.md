- **Editing pitfalls learned the hard way**
  - GDScript uses tabs. With Python patches use exact anchors and **assert the anchor exists**; make patch scripts idempotent. Write patch scripts with the **Write tool to a scratchpad `.py` file** and run them; long bash heredocs containing quotes/Greek can fail with "unexpected EOF". PowerShell scripts with Greek need UTF-8 BOM.
  - Write Greek with the Write/Edit tools (UTF-8). Don't use `%%` in non-formatted Greek strings.
  - Windows sometimes throws `OSError [Errno 22]` when reading a file just written: retry.
  - `rm -f "$VAR"/*` is blocked by a safety check; just overwrite files instead.
  - `.uid` files are generated by the import and are committed. CRLF-to-LF warnings on commit are harmless (`.gitattributes` forces LF).
  - A long animation (spin) must be ended by a timer (`_end_skill_attack`). `Variant` inference: write `var x: bool = ...` / `var s: String = dict["k"]`. Scripts in `--script` tests cannot use a `class_name` that mentions an autoload (see above).
  - Do not scale a physics body in a tween (scale the visual child).
  - **Headless logic tests:** `timeout 100 godot --path . --headless --script tools/<name>.gd > /tmp/t.txt 2>&1; grep "^PASS\|^FAIL\|SCRIPT ERROR" /tmp/t.txt`. A script error inside a test coroutine leaves Godot hanging (it never reaches `quit()`), so ALWAYS use `timeout`. The harmless engine message `Parameter "t" is null` and `N resources still in use at exit` appear on `main` too.
  - **Stopping a hung test:** with PowerShell filter on `Name -like 'Godot*'` AND the test name in the command line; a filter on the command line alone also matches the `bash.exe` that launched it. Never touch Theodore's editor/game processes.
  - **Plan/anchor check:** to verify a plan, a small Python script reads the plan, takes every fenced block that follows an `old_string:` line and asserts `source.count(block) == 1` in the target file (read as UTF-8, `\r\n` -> `\n`). It found a wrong indentation in two plans. Edit-tool anchors may be a single line without leading tabs (the original indentation stays).
  - Appending a long block to a script: write it with the Write tool to a scratchpad file and `cat "$FILE" >> scripts/x.gd` (bash heredocs with quotes/Greek fail).
  - **Shader noise breaks far from the origin** (float precision at x = -6000 gave hard squares): the ground/path/patch shaders have a `world_offset` uniform (`Terrain.set_world_offset`).
  - Frame-rate checks: `perftest` can read 47 to 58 fps once when another process is running; re-run before assuming a regression (the baseline is 60 fps, compare with `git switch main` if in doubt).
  - Tests that call `SaveGame.save()` must back up and restore `savegame.json` AND `savegame.bak` (the first `part3_hooks_test` run overwrote the `.bak` of his save before this was fixed; `savegame.json` itself was never lost).
