- Επέκταση της βασικής μπάρας δεξιοτήτων σε 12 θέσεις (πλήκτρα 9, 0, -, =).
- Νέα επιλογή στις Ρυθμίσεις για ενεργοποίηση δεύτερης μπάρας δεξιοτήτων.
- Η δεύτερη μπάρα τοποθετείται ακριβώς κάτω από τη βασική με άλλες 12 θέσεις.
- Πλήρης υποστήριξη αντιστοίχισης πλήκτρων (keybindings) για όλες τις 24 θέσεις.
