# Horse / Mount Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** George can buy a horse from a stable keeper and ride it anywhere outdoors: one key mounts and dismounts, the horse is 1.8x faster, and any fight (a hit, an attack, a skill) throws him off.

**Architecture:** The rules (price, level, speed factor, who may mount) live in a pure helper `MountRules` (tests type-reference it). The CC0 Quaternius horse (`assets/animals/Horse.fbx`) is wrapped by a `Horse` node that sizes itself, finds its animations by name and follows the rider's speed. `Player` gets `horse_owned` (saved) and `mounted`, a `mount` input action, and a small `_update_mount()` that handles the key and every dismount trigger. A stable yard with the keeper Μανώλης (an ordinary `Npc` with a `"shop": "stable"` entry) sells the horse through the existing shop window.

**Tech Stack:** Godot 4.7 GDScript (tabs), FBX import, numpy audio recipes (`tools/audio`), headless `--script` tests in `tools/`.

## Global Constraints

- All in-game text is Greek (strings in `scripts/strings_el.gd`, NPC data in `scripts/quest_data.gd`, shop data in `scripts/shop_data.gd`); code, comments and file names are English.
- GDScript files use TAB indentation. Write/Edit Greek text with the Write/Edit tools (UTF-8), never with a shell heredoc.
- Buy the horse for 350 gold at level 5 (`MountRules.PRICE`, `MountRules.MIN_LEVEL`); speed factor 1.8 (`MountRules.SPEED_FACTOR`); chase range 30 m.
- Summon anywhere (no horse to walk back to); travel only (hit, attack or skill key dismounts, no mounting while a skeleton is chasing). Combat is unchanged.
- Mount key is G by default, rebindable (settings list `GameSettings.REBINDABLE`), listed in `Strings.CONTROLS_HELP`. `horse_owned` is saved; `mounted` is not.
- Allowed in the open village, the Frontier and during invasions; not indoors.
- Keeper: **Μανώλης ο Ιπποκόμος**, stable yard at world (63, 53) (open ground found with a probe on 2026-10-13: nothing within 10 m, no path within 8 m).
- Credit the Quaternius pack (CC0, https://quaternius.itch.io/lowpoly-animated-animals) in `THIRD_PARTY_NOTICES.md` and the Credits page.
- Out of scope: fighting mounted, stamina, horse colours or upgrades, a horse that stays where it was left, the other animals of the pack.

Work on a feature branch `feature/mount`; do not push, tag or release (the release of boss nights + mount together as 1.1.0 is done only when he asks; its prep is in `git stash` "release 1.1.0 prep").

```gdscript
class_name MountRules
extends RefCounted
## The rules of the horse. Pure functions, no scene access, so tests can use them directly.

const SPEED_FACTOR := 1.8        # riding speed relative to walking or running on foot
const PRICE := 350               # gold at the stable
const MIN_LEVEL := 5
const CHASE_RANGE := 30.0        # a skeleton this close and chasing stops George from mounting
const CHASE := 2                 # Enemy.State.CHASE
const ATTACK := 3                # Enemy.State.ATTACK


static func can_buy(level: int, gold: int, owned: bool) -> bool:
	return not owned and level >= MIN_LEVEL and gold >= PRICE


## Why George cannot mount right now: "" means he can. The order is the order of importance.
static func block_reason(owned: bool, indoors: bool, busy: bool, dead: bool, stunned: bool, chased_now: bool) -> String:
	if not owned:
		return "not_owned"
	if dead:
		return "dead"
	if indoors:
		return "indoors"
	if busy:
		return "busy"
	if stunned:
		return "stunned"
	if chased_now:
		return "chased"
	return ""


## `states` are the `_state` values of the enemies (Enemy.State), `distances` how far each is from George.
static func chased(states: Array, distances: Array) -> bool:
	for i in states.size():
		if (states[i] == CHASE or states[i] == ATTACK) and float(distances[i]) <= CHASE_RANGE:
			return true
	return false
```

```
@sfx("footstep_hoof", 3, 0.42)
def _(rng, i):
    # two quick hoof knocks (a trot): a hard click on top of a short wooden thump
    out = np.zeros(int(0.32 * S.SR))
    for k, t0 in enumerate([0.0, 0.11]):
        knock = S.bandpass(nz(0.12, rng), 1800 + 220 * i + 150 * k, 1500) * S.expdecay(int(0.12 * S.SR), 0.02)
        S.place(out, knock * 0.9 + thump(130 + 12 * i, 0.12) * 0.6, t0 + 0.012 * k * i)
    return out


@sfx("horse_whinny", 1, 0.7)
def _(rng, i):
    # a rising neigh: a sawtooth with a wavering pitch through two vowel-like bands, then a short breath
    dur = 0.9
    n = int(dur * S.SR)
    t = np.linspace(0, 1, n)
    f = 520 + 520 * np.sin(np.pi * np.clip(t * 1.25, 0, 1)) ** 0.6 + 40 * np.sin(2 * np.pi * 14 * t)
    voice = np.zeros(n)
    phase = 2 * np.pi * np.cumsum(f) / S.SR
    for h in range(1, 12):
        voice += np.sin(h * phase) / h
    voice = S.formants(voice, [(900, 300, 1.0), (2300, 500, 0.6)])
    voice *= swell(n, 0.35)
    breath = S.bandpass(nz(0.3, rng), 1500, 900) * swell(int(0.3 * S.SR), 0.2) * 0.25
    out = np.zeros(int(1.3 * S.SR))
    S.place(out, voice * 0.7, 0.0)
    S.place(out, breath, 0.8)
    return out
```

```gdscript
class_name Horse
extends Node3D
## The riding horse: the Quaternius "Farm Animals Animated" horse (CC0, assets/animals/Horse.fbx),
## sized to a believable length, standing on y = 0 with its nose toward +Z (like the KayKit
## characters), with Idle / Walk / Run / Jump picked by the speed the rider gives it.

const MODEL := "res://assets/animals/Horse.fbx"
const TARGET_LENGTH := 2.5          # nose to tail in metres after scaling
const SEAT_HEIGHT := 1.35           # how high George's model sits above the ground while riding (tuned by eye in mountshot)
const FACING_FLIP := false          # true if the model's head points toward -Z
const WALK_MAX := 11.0              # up to this speed (m/s) the horse walks, above it it runs

var length_m := 0.0
var height_m := 0.0

var _model: Node3D
var _anim: AnimationPlayer
var _names := {}                    # kind ("idle", "walk", "run", "jump") -> animation name in the model
var _kind := ""
var _standing := false


func _ready() -> void:
	_model = (load(MODEL) as PackedScene).instantiate() as Node3D
	add_child(_model)
	var raw := _box()
	# the longest horizontal side is nose to tail: turn the model so that it lies along Z
	if raw.size.x > raw.size.z:
		_model.rotation.y = PI / 2.0
	if FACING_FLIP:
		_model.rotation.y += PI
	var rotated := _box()
	var s := TARGET_LENGTH / maxf(rotated.size.z, 0.01)
	_model.scale = Vector3.ONE * s
	var fitted := _box()
	# feet on the ground, centred on x and z
	_model.position -= Vector3(fitted.get_center().x, fitted.position.y, fitted.get_center().z)
	var final := _box()
	length_m = final.size.z
	height_m = final.size.y
	_anim = _model.find_child("AnimationPlayer", true, false) as AnimationPlayer
	if _anim != null:
		for kind in ["idle", "walk", "run", "jump"]:
			_names[kind] = _find(kind)
		for kind in ["idle", "walk", "run"]:
			if _names[kind] != "":
				_anim.get_animation(_names[kind]).loop_mode = Animation.LOOP_LINEAR
	_play("idle")


## The model's mesh box in this node's own frame.
func _box() -> AABB:
	var inv := global_transform.affine_inverse()
	var box := AABB()
	var have := false
	for mi in _model.find_children("*", "MeshInstance3D", true, false):
		var a: AABB = (inv * (mi as MeshInstance3D).global_transform) * (mi as MeshInstance3D).get_aabb()
		box = a if not have else box.merge(a)
		have = true
	return box


func feet_y() -> float:
	return _box().position.y


## The animation of this kind ("" when the model has none). The match is by the end of the name,
## so "Horse|Run" and "Run" both work, and "Walk" does not match "WalkSlow".
func animation_for(kind: String) -> String:
	return _names.get(kind, "")


func current_kind() -> String:
	return _kind


func _find(kind: String) -> String:
	for n in _anim.get_animation_list():
		if String(n).to_lower().ends_with(kind):
			return String(n)
	return ""


## The rider's horizontal speed and whether he is on the ground.
func set_motion(speed: float, on_floor: bool) -> void:
	if _standing or _anim == null:
		return
	if not on_floor and _names.get("jump", "") != "":
		_play("jump")
	elif speed < 0.3:
		_play("idle")
	elif speed <= WALK_MAX:
		_play("walk")
		_anim.speed_scale = clampf(speed / 9.0, 0.8, 1.4)
	else:
		_play("run")
		_anim.speed_scale = clampf(speed / 16.0, 0.8, 1.3)


## For the stable: idle forever, whatever the rider does.
func stand() -> void:
	_standing = true
	_play("idle")


func _play(kind: String) -> void:
	if _anim == null or _kind == kind:
		return
	var name: String = _names.get(kind, "")
	if name == "":
		return
	_kind = kind
	if kind == "idle":
		_anim.speed_scale = 1.0
	_anim.play(name, 0.2)
```
